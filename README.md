# Taskflow Kanban demo

A frontend-only React and TypeScript Kanban board with hardcoded sample data. The UI intentionally mixes component styles—radii, shadows, typefaces, badge treatments, and controls—so it can be used as a component-library refactoring exercise.

## Run locally

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```
